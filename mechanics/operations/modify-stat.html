MODIFY_STAT

MODIFY_STAT changes a consumable's current pool: a heal, a spend, or a fill. It skips a stat that has no stat_consumable_config, and it does not write the stat's level. A level change is MODIFY_STAT_LEVEL or OVERLAY_STAT_LEVEL. The op only writes entities, so a location rule such as CURSOR resolves to nobody. ADD_PERCENT takes a fraction. 0.25 is 25 percent of the reference, and 25 is twenty-five times that reference. Default value_base is CURRENT. Use MAX when the percent should be of the pool cap. An amount that names an event value is skipped when that value is empty.

Task: operation_modify_stat. Smoke: mechanic_example_modify_stat in pirate-era-core-frontend/Mechanics/mechanic_examples.dsc.

Consumable current only (heal / damage / fill). Skips stats that have no stat_consumable_config. Does not write levels.

This op always overlays target_type to ENTITY. Location-only rules (CURSOR) resolve to nobody. Targeting keys still go through resolve_mechanic_operation_targets.

typeyesMODIFY_STAT
statyesConsumable stat script name (stat_stamina or stamina)
amountyesFlat number, stat_* via resolve_mechanic_value, or a mechanic_event_values key (damage, value, …)

targetnoWho. See targeting.md
originnoAOE search center. Default CASTER
rangenoLOOK ray, or AOE radius around origin
origin_rangenoLOOK / CURSOR ray when those are origin

stat_operation values (rules.dsc mechanic_stat_operations):

ValueResult
ADD_FLATcurrent + amount (negative amount is damage). Ignores value_base
ADD_PERCENTcurrent + reference * amount. CURRENT: 2 and 0.5 gives 1. MAX: max 20 and 0.5 gives 10
MULTIPLYreference * amount
SETamount. Ignores value_base

Unknown stat_operation skips the write. Clamp (floor depletes_to, cap the computed stat max) happens inside set_consumable_stat_value.

Full Scalable Value Config (base/max/minLevel/maxLevel/equation on the op) is not wired. Use a number, a stat_* ref, or an event value key.

self_heal_stamina:
    operations:
        1:
            type: MODIFY_STAT
            target: SELF
            stat: stat_stamina
            stat_operation: ADD_FLAT
            amount: 5

Percent of max (current 2, max 20, amount 0.5 restores 10):

self_heal_stamina_percent_max:
    operations:
        1:
            type: MODIFY_STAT
            target: SELF
            stat: stat_stamina
            stat_operation: ADD_PERCENT
            value_base: MAX
            amount: 0.5

Check /stats for Currently on stamina.
