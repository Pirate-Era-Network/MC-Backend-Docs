# Effects and velocity

`play_effect_*` and `apply_velocity_*`. The operations are [PLAY_EFFECT](../mechanics/operations/play-effect.md) and [APPLY_VELOCITY](../mechanics/operations/apply-velocity.md).

| Key | Role | Page |
| --- | --- | --- |
| `play_effect_kinds` | PARTICLE / LIGHTNING / BLOCK_CRACK / SCREEN_SHAKE / BLOODY_SCREEN / BLOCK_EXPLOSION / DEBRIS / DROP_BURST / EffectLib shapes | [mechanics/operations.md](../mechanics/operations/README.md) |
| `play_effect_lib_types` | Case-sensitive EffectLib type names | [mechanics/operations.md](../mechanics/operations/README.md) |
| `play_effect_lib_keys` | YAML to EffectLib `effect_data` names | [mechanics/operations.md](../mechanics/operations/README.md) |
| `play_effect_particle_aliases` | Legacy particle names to current names | [mechanics/operations.md](../mechanics/operations/README.md) |
| `play_effect_defaults` | Quantity, lightning sound, blockcrack defaults | [mechanics/operations.md](../mechanics/operations/README.md) |
| `apply_velocity_modes` | KNOCKBACK / PULL / GUIDE / GROUND | [mechanics/operations.md](../mechanics/operations/README.md) |
| `apply_velocity_directions` | AWAY / TOWARD / LOOK / FORWARD | [mechanics/operations.md](../mechanics/operations/README.md) |
| `apply_velocity_defaults` | Amount, Y, stop_distance, tickrate, loop duration | [mechanics/operations.md](../mechanics/operations/README.md) |
