# AREA

`AREA` fills when `fire_quest_area_enter` runs for a successful player enter of `area`. The id matches the placed area or the template script name. The prefix `area_` is optional on either side.

File: `Quests/objectives/objective_area.dsc`. Shared objective keys are on [Quests](../README.md).

```yaml
enter_gate:
    type: AREA
    area: area_example_gate
```
