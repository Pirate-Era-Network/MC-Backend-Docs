# SELECTION

`SELECTION` is a carousel. The three item slots are 20, 23, and 26, and the select button is 3 wide. The middle item and the order index are `runtime_data.menu.kind.selection_item` and `selection_index`.

`orderlist` is a numbered map (`1:`, `2:`). A YAML list of maps does not load. Shared slot keys are on [Menus](../README.md).
