# SCROLL

`SCROLL` is a moving window over `scroll_list`. Fat is 3 boxes, 2 slots high. Slim is 6. Optional `quest_box` or `npc` extras go on the title. The window start is `runtime_data.menu.kind.scroll_index`.

`scroll_list` is a numbered map (`1:`, `2:`). A YAML list of maps does not load. Shared slot keys are on [Menus](../README.md).
