# Contract prefixes

These prefixes are still in `script_prefixes` and have no engine. When an engine lands, move the row onto its own page and mark it Live. Do not treat a row here as something the player can already use.

| Prefix | Reserved for |
| --- | --- |
| `npc_` | A static NPC whose left and right click would run mechanics |
| `dialogue_` | A node graph. [OPEN_DIALOGUE](mechanics/operations/open-dialogue.md) is a chest kind and is already Live. This prefix is not that chest |
| `repairprofile_` | Repair YAML. Spend is `APPLY_TRANSACTION`. See [items](items/README.md) |
| `levelprofile_` | A level-profile script. Still Contract |
| `castset_` | A hotbar overlay set on a mount. See [mounts](mounts.md) |
