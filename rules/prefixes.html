Prefixes

This is every prefix the reload walk collects. A row marked Contract has no engine yet. Those names are also on Contract prefixes.

Each entry has type (usually data) and value (the name prefix). Reload collects util.scripts whose name starts with value.

Prefix key in rulesPrefix stringStatus
