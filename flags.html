Player flags

Partial. Paths come from rules.dsc flag_saves. Getters and setters exist for stats, currencies, living-entity bind, language, triggerable bind, casting session, trigger cooldowns, SkillMove category bans, gear slot ids, cosmetic persist channels, season pass counters, vault slot maps, daily reset period stamps, and quest progress.

Persisted paths start with data.. Runtime paths start with runtime_data..

World areas are not a player flag. The index is the server flag area_index. Groups are the server flag area_group_index. See areas.md.

Placed waypoints are not a player flag. The index is the server flag waypoint_index. A waypoint_ script with the same id keeps requirements and cost. See travel.md.

Mongo later serializes the flag_saves set through getters. Do not persist runtime-only keys until you decide they belong here. Menu open-state lives in menu_runtime_flags, not flag_saves. Triggerable bind lives in triggerable_runtime_flags. HUD SHOW/HIDE overlays live in hud_runtime_flags. See menus.md, triggers.md, and HUD.

What can go wrong​

  • Using data.consumable_stats as the path. The real path is data.consumed_stats.
  • Writing data.classes. Unused leftover. Class progress is pack stats under data.stats.
  • Writing the whistle id as data.mounts.equipped. That key is read as a mount row. The id is data.equipped_mount. See mounts.md.
  • Writing cosmetic display ids into data.gear. Those belong on data.cosmetic_persist. Gear is EQUIP_GEAR. Cosmetics are EQUIP_COSMETIC. Frontend may run both. Backend does not spawn a stand from a gear id.
  • Writing pepass flags. Season pass persist is data.season_pass.
  • Writing vault items onto a gui: true menu. Use OPEN_STORAGE. See vaults.md.
  • Writing trade items onto a gui: true menu. Use OPEN_TRADE. See trades.md.
  • Writing these flags in a mechanic or join event. Use the domain setter.
  • Writing data.quests from a mechanic. Use START_QUEST, ADVANCE_QUEST, and COMPLETE_QUEST. See quests.md.
  • Writing HUD SHOW/HIDE overlays onto data.hud.layout. Persist is the layout id only. Overlays are runtime_data.hud.
