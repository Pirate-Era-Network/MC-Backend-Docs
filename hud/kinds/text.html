TEXT

A text part prints a transcript key or a literal string.

Shared row keys are on the layout page. Width keys (maxchars, pad, counter, color) work the same way as on a stat.

KeyWhat to write
fontShort name from appearance.
textA transcript key such as hud_stunned_text, or a literal.
maxcharsWidth of the line.
padFill character. Z keeps the width.
counterLeft-side twin. Z matches the pad.
colorOptional. Quote a value that contains #.

Custom-font copy stays lowercase. The font has no capital glyphs for words.

hudpart_stunned_text:
    type: data
    debug: false
    data:
        kind: TEXT
        font: hotbar_alphabet
        text: hud_stunned_text
        maxchars: 8
        pad: Z
        counter: Z
        priority: 10

Put the words in the transcript under that key, in lowercase:

hud_stunned_text: stunned

Tips​

  • Store player-facing words as a transcript key. A literal still works for a string you will not translate.
  • Keep custom-font words lowercase.
  • This part is usually an extra. Leave it out of the base row and show it with SHOW_HUD_PART. Keep balance on PAIR.
