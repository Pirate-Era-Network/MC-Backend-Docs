Layout

Write a hud_ script when a whole row should be reusable, such as the combat bar or a shorter bar for a cutscene. The script is type: data. The row lives under data.parts as 1:, 2:, in draw order. Minecraft centers the whole string, so the first slot is the pin (the hotbar letter in this pack) and every later slot is a distance from that pin. The player stores one layout id. Another hud_ script stays unused until SET_HUD_LAYOUT replaces that id, and the previous row stops drawing. A temporary icon on the same bar is SHOW_HUD_PART, which draws an extra piece on that stored row.

The hotbar letter is the pin, then a health bar sits beside it.

hud_combat:
    type: data
    debug: false
    data:
        parts:
            1:
                part: hudpart_hotbar
                offset: 0
                balance: RAW
            2:
                part: hudpart_hp_bar
                offset: -280

hudpart_hotbar is a glyph. hudpart_hp_bar is a bar. The kind pages list only the keys that kind draws. The keys below are shared.

Shared keys​

KeyWhereWhat to write
partRowhudpart_ script name. The prefix on the value is optional.
offsetRow or partDistance from the pin, as a negative space count. The row wins when both set it. 0 sits on the pin.
balanceRow or partPAIR is the default. It draws a matching blank on the left so the pin does not drift. RAW means this slot is the pin, and only the first hotbar letter uses it. The row wins when both set it.
enabledRowfalse still draws the off-state for that slot. To force the pad, use HIDE_HUD_PART.
requirementsRow or partNumbered map, same shape as a mechanic. The row wins when both set it. Types are on requirements.
priorityPartDraw order for an extra shown on top of the base row. Higher paints later. Default 0.

A requirement on the part:

requirements:
    1:
        type: BOOLEAN
        stat: stat_haki_unlocked
        mode: HAS

With no presence op, a failed requirement draws the pad and the slot stays. That is the right choice in the middle of a row. SHOW_HUD_PART on the part omits it when the requirement fails. HIDE_HUD_PART on the part draws the pad when the requirement passes.

Tips​

  • The first hotbar letter is balance: RAW. PAIR on that letter adds a left counter and shifts the whole bar.
  • A tier-2 extra stays PAIR. An extra is a part that is not in this parts row. A skill shows it with SHOW_HUD_PART. RAW on that extra has no left counter, so the base bar slides.
  • SHOW omit belongs on the last slot, or on an extra that is not in the base row. A middle slot that fails its requirement still draws its pad.
  • Reload rebuilds the layout cache and marks each online player dirty. The next draw uses the new offsets. Temporary show and hide parts stay.
