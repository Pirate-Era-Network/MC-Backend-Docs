How the framework works

Live. Backend is the engine (tasks, procs, world events). Frontend is type: data configs. They share vocabulary through rules.dsc.

Split​

SideRepoJob
Backendmc-denizen-core-backendLogic, getters/setters, mechanic dispatcher
Frontendpirate-era-core-frontendStats, items, currencies, living entities, mechanic examples, menus, HUD, daily reset, language

Do not put Pirate Era names in Backend. Do not put engine tasks in Frontend.

Discovery (prefixes)​

On reload, reload_all_server_flags walks rules.dsc script_prefixes. Git sync runs it from reload_all_scripts after ~reload. /ex reload hits after reload scripts in global_events. For each prefix it stores matching script names on the server:

server.flag[scripts.stat_] is the list of all stat_* data scripts.

A longer prefix that starts with a shorter one is stored on both lists. questcategory_ also matches quest_. entityai_, entityanimation_, entitymodel_, entityskill_, and entityprofile_ also match entity_. Lookups for the short prefix must skip those longer names. castset_ is a ride hotbar set. mount_ is reserved and unused. The ride block is entity_.mount. See mounts.md.

Script names keep the prefix (stat_stamina). Flag keys on the player strip it (data.stats.stamina). See flags.md.

Getters and setters​

Feature scripts do not write - flag <player> .... Reads and writes go through a domain util. Flag paths come from get_rule_value. Target-aware scripts - inject set_target. Loot grant uses Cost Component GIVE (apply_player_cost_delta) for ITEM and CURRENCY. Currency spend uses APPLY_TRANSACTION. Wallet versus item convert is /withdraw and /redeem.

Mechanics in one line​

Something builds a context map (build_mechanic_context) and fires run_mechanic_config. That raises custom event execute_mechanic. Requirements run, then delay/repeat, then each operation. Operations call resolve_mechanic_operation_targets. World events reach this through fire_stat_event (triggers.md). Details: mechanics/README.md.

What can go wrong​

  • Naming a Frontend script without its prefix. It never lands in server.flag[scripts.*].
  • Reloading Backend without Frontend (or the reverse). Prefix lists go empty for that side.
  • Writing flags in a mechanic op. Persistence and path changes then break in many files.
